O que falta para ativar

Este app não simula login. Para o acesso real com conta Google, é preciso criar credenciais OAuth no Google Cloud Console e configurá-las no ambiente.

  1. Crie um projeto e uma credencial OAuth 2.0 (tipo "Aplicativo da Web").
  2. Cadastre a URL de redirecionamento http://127.0.0.1:5001/perfil/google/callback.
  3. Defina as variáveis de ambiente GOOGLE_CLIENT_ID e GOOGLE_CLIENT_SECRET.
  4. Passe a usar a biblioteca authlib ou google-auth para trocar o código pelo token.
